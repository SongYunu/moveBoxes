## 성공한 시연에만 적용하는 효율 가중치

현재 모델은 **Stage ACT**입니다. 이 변경은 디퓨전 모델의 조건 입력이나 강화학습 보상이 아니라,
행동 모방 손실에 적용하는 **시연별 가중치**입니다. 관측 입력과 모델 크기는 그대로 유지합니다.

- 네 상자 완주 시연: 학습 분할에 속한 완주 시연끼리 최초 완주 행동 수를 비교합니다.
- 빠른 완주 시연에는 최대 `1 + efficiency_bonus` 배의 가중치를 줍니다. 기본값은 최대 **1.5배**입니다.
- 세 상자 부분 성공 시연은 속도와 관계없이 **1배**입니다. 최소 3개에도 못 미친 시연은 학습에 넣지 않습니다.
- 완주 시연이 2개 미만이거나 모두 같은 행동 수이면 효율 보너스를 주지 않습니다.
- 검증 시연은 모두 1배로 평가합니다. 가중치 산출에 검증 시연의 속도를 사용하지 않습니다.

완주한 학습 시연의 가장 짧은/긴 완주 행동 수를 `T_min`, `T_max`라 할 때:

```text
w = 1 + efficiency_bonus * (T_max - T) / (T_max - T_min)
```

모델 선택은 **분류 정확도 → 네 상자 완주율 → 완주한 실행들의 평균 완료 행동 수 → 첫 집기 비율** 순서입니다.
성공 개수가 줄어든 모델을 빠르다는 이유로 선택하지 않습니다. 완주 실행이 없으면 시간으로 우열을 가리지 않습니다.
완료 행동 수는 실제 환경의 `success_count`를 매 행동 경계에서 확인해 기록합니다.
실패 실행의 기본 `mean_steps` 값을 빠른 성공으로 오인하지 않습니다.

## 예산과 재개

배치 32, 기존 약 1.4M 모델, AMP를 유지합니다. 1,000회마다 8회 개발 평가를 하며 최대 12,000회 학습합니다.
4구간 연속 개선이 없으면 종료합니다. 시작 모델도 같은 개발 시드로 평가하고, 더 나은 체크포인트를 보존합니다.
개발/테스트/최종 시드는 각각 54000/44000/74000부터, 시연 시험/수집은 122000/123000부터입니다.

학습 **전** 수집 한도만 더 늘릴 때는 실행 객체에 적용하고 같은 수집 셀을 다시 실행할 수 있습니다:

```python
CFG['deadline_max_attempts'] = 256
experiment.cfg['deadline_max_attempts'] = 256
_ = experiment.collect_deadline('collect')
```

완료된 시연은 유지합니다. 시연 수·시도 수·시험 횟수·호출당 시간 예산을 변경해도 이미 수행한 시드를 반복하지 않습니다.
학습이 시작된 뒤 데이터 목표를 늘리거나 학습 총량을 바꾸려면 별도 `run_name`을 사용합니다.
optimizer와 학습률 일정에 영향을 주는 변경을 같은 학습의 재개로 취급하지 않습니다.

결과는 GitHub의 `run-moveboxes_medium_curriculum_v21_benchmark` Release에 저장합니다.
새 런타임에서 같은 설정으로 01~05를 실행한 뒤 07 또는 08을 재개합니다.
데이터 수집 교사는 패키지에서 제외하며, 제출 정책은 학습된 Stage ACT입니다.
