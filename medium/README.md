# Medium 집중 실험

[Medium 전용 Colab](https://colab.research.google.com/github/SongYunu/moveBoxes/blob/main/medium/notebooks/moveboxes_medium_colab.ipynb)을 Colab 2026.07 / Python 3.12 / T4에서 실행합니다.

코드와 방법별 하위 모듈은 `medium/code/`, 노트북은 `medium/notebooks/`, 버전 설명은
`medium/docs/`, 검사는 `medium/tests/`에 있습니다.

| 셀 | 내용 |
|---|---|
| 01~04 | 설정, Git 코드 로드, GitHub 인증/복원, 설치 |
| 05 | Medium GPU 확인, 데이터 및 기존 Medium 성공 시연·모델 준비 |
| 06 | 2,000회 학습 → 실제 환경 평가 반복. 중단 후 같은 셀로 재개 |
| 07 | 최고 모델 별도 8회 테스트·영상·2회 행동 기록 |
| 08 | 구간별 성적 확인 |
| 09 | 목표 달성 모델의 별도 시드 최종 100회 평가 |
| 10 | 최종 평가를 완료한 Medium 모델 패키징 |

Easy 집중 실험과 같은 Stage ACT 학습 방식을 사용합니다. Medium 관측은 72차원이며 상자는 4개입니다.
실행 시와 같은 zero-latent 경로로 행동을 학습하고, 첫 집기 구간을 30% 확률로 별도 표집합니다.
나머지 표집에는 운반·놓기·다음 상자와 복구 시연이 포함됩니다.

기본값은 2,000회씩 최대 10구간입니다. 각 구간 뒤 예측 평균화 1/4 설정을 각각 8회 평가하며,
분류 정확도 → 네 상자 모두 정답인 비율 → 첫 집기 비율 순서로 최고 모델을 보존합니다.
네 상자 정답 비율 95% 이상이 2구간 연속이면 종료합니다. 기본 평가 8회에서는 8회 모두 성공해야 이 기준을 통과합니다.
4구간 연속 개선이 없거나 총 학습 예산에 도달해도 종료합니다. 목표 미달이면 09 최종 평가는 생략합니다.
이 목표는 학습 종료 조건이며 실제 성능을 보장하지 않습니다.

기존 `moveboxes_stage_act_v1` 실행에서 Medium 성공 시연과 마지막 모델을 가져옵니다.
기존 Medium 모델이 없다면 01 셀에서 `source_run_name=None, warm_start=False`로 설정하여 시연 수집부터 시작합니다.
Easy 모델은 Medium과 관측 크기가 다르므로 가져오지 않습니다.

새 결과는 `run-moveboxes_medium_lab_v1_benchmark` GitHub Release에 저장합니다.
기존 Easy 및 단계 v1 결과는 유지합니다. 계정/런타임을 바꾸면 같은 설정으로 01~05를 실행하고 06을 재개합니다.
변경된 학습 설정으로 별도 실험을 할 때는 새 `run_name`을 사용합니다.

개발 평가 시드는 50000부터, 별도 테스트는 40000부터, 최종 평가는 70000부터입니다.
평가 한도는 기존 200스텝을 유지합니다. CPU 검증은 학습·중단 재개·모델 선택과 네 상자 성공 판정을 다룹니다.
실제 물리 환경의 성능은 Colab GPU 테스트와 영상으로 확인합니다.
